#Day 04 文件指纹学习记录
## 1.学习目标
实现fingerprint_file(),理解文件哈希，二进制读取和分块操作
## 2.学习内容
###2.1 文件指纹
根据文件内容生成固定长度的哈希值
本次学习使用：
- MD5
- SHA-256

### 2.2 rb模式
计算文件哈希时使用二进制模式读取
with open(file_path,"rb“) as f:
读取结果为bytes.

### 2.3 分块读取
避免大文件一次性占用内存

## 3.实验结果
| 实验 | 预期 | 实际结果 |
|---|---|---|
| 同内容不同文件名 | hash 相同 | True |
| 不同内容 | hash 不同 | False |
| 同名不同内容 | hash 不同 | False |
| chunk_size=4 vs 8192 | hash 相同 | True |

## 4.总结
通过今天学习，理解了文件指纹不是通过文件名产生而是通过文件内容生成
分块处理不会改变最终哈希结果。
Rag系统利用文件指纹对文件进行去重，从而避免重复进行文本切片，Embedding和向量入库。
